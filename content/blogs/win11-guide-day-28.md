以前畫出來很醜的圖，總會被嘲笑：「你是用小畫家畫的喔？」不過在 Windows 11 上，小畫家已經進化到令人驚艷的境界！

在 **Day 2** 我們介紹了小畫家 **一鍵去背** 功能，而今天要帶來的更是超猛的功能——**Image Creator**！

有想法卻畫不出來？別擔心，小畫家 Image Creator 幫你實現任何天馬行空的創意。

---

### 如何啟用 Image Creator

要使用這個功能，必須切換到支援的地區(筆者寫這邊文章的時候，台灣區域目前不支援這個功能)：

1. 按下 **Win + I** 打開「設定」。
2. 前往 **時間與語言** > **語言與區域**。
3. 在「區域」部分，選擇支援的地區，如 **美國**。

目前 Image Creator 僅在以下地區開放：**美國、法國、英國、澳洲、加拿大、義大利、德國**。

---

### 試玩：讓貓咪幫我 Code Review

為了測試 Image Creator，我輸入了以下 Prompt：

> 貓咪站在筆電鍵盤上，幫我做 code review，牠是一隻可愛的三花貓。

使用 Image Creator 時，你會獲得 50 點初始點數，每次使用需要支付 1 點（我現在剩 49 點 😆）。

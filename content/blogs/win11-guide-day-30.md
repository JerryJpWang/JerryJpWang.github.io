## Go Back or Stay? 會退回去 Windows 10 嗎？

**不會，這次會繼續使用Windows 11 為日常作業使用OS**

### 為何升級 Windows 11？

對筆者來說，兩個最重要的因素是：

- **`安全、安全、安全`**
- **免費、免費、免費**

---

## 開發者的體驗

Windows 11 23H2 已達穩定版本，能完成日常開發所有任務。我日常使用的工具如 Docker Desktop、VS Code、Visual Studio、SSMS、Fork、Chocolately、VirtualBox 等，都在 Windows 11 上運行良好。

### Phone Link

手機與電腦整合度提高，在參加研討會時，講者速度快，來不及手寫筆記時，我會透過拍照，再透過 Phone Link 搭配 Snipping Tool Text Actions 功能圖片轉成文字，方便複製貼上長網址或內容，提升效率。

(Tip: 透過Phone Link 把手機端的網址分享到電腦端，就可以在電腦端，自動開啟瀏覽器的新分頁來瀏覽資訊。)

---

## 重點工具與功能

1. **Windows Terminal**
   - 預設使用 Terminal，支援分頁管理，乾淨且方便。
   - Windows 11 的檔案總管也採用類似設計，減少來回切換頁面的煩惱。
2. **Snap Layout**
   - 提升視窗管理效率，適合多工場景。
3. **小畫家 Image Creator**
   - 小畫家現在支援去背與圖層功能，對於筆者製作簡報或筆記十分實用。
   - **Image Creator**，給出你的想法，小畫家 Image Creator 就可以幫你實現你的創意
4. **右鍵選單**
   - 可以自定義傳統選單 **[(Day 8) Windows 11 右鍵選單變更教學：輕鬆恢復傳統選單，提升操作效率](https://ithelp.ithome.com.tw/articles/10358917)** 。
   - 或使用快捷鍵「Shift + 右鍵」快速開啟。

## 穩定性與使用心得

- **穩定性 Ready**：參與鐵人賽期間使用 23H2 版本，無遇當機或藍屏問題。
- **UI 彈性**：開始選單支援置中或置左調整，適合不同用戶習慣。

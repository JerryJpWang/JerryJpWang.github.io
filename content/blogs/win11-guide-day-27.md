## **白鶴清酒**：中型企業 (50–999 名員工)

[案例詳細連結](https://customers.microsoft.com/en-us/story/1686820283958916773-hakutsuru-sake-story)

### 部署 Windows 11 Pro 的無縫過渡

從早期版本的 Windows 遷移至 Windows 11 Pro 的過程非常順利，讓資訊系統部門負責人 **Katsube 先生**印象深刻：

> “一切都可以與 Windows 11 Pro 無縫協作。”

對白鶴來說，**相容性至關重要**，因為該公司使用了多個自家開發的專有應用程式。Katsube 表示：

> 「它們運行沒有問題，過渡比預期順利，員工在使用時沒有任何困惑。」

這家擁有 **280 年歷史**的企業也未固守舊方式，透過 **TPM 2.0** 和其他安全技術，全公司部署了 Windows 11 Pro：

> 「Windows 11 Pro 幫助我們統一了國內外業務，提升了生產力和安全性。」

---

### 加強安全性：TPM 2.0 的貢獻

作為 **Hakutsuru** 資訊系統部經理，**Katsube** 支援了全球 22 個據點的員工。疫情期間，公司轉向靈活的工作模式，面對網路威脅，他選擇透過 Windows 11 Pro 的 **硬體支援保護** 來應對：

> 「我們的 IT 部門也因此受益，透過 Windows 11 Pro 的工具提升了工作效率。」

---

## **豐田通商**：大型企業 (10,000+ 名員工)

[案例詳細連結](https://customers.microsoft.com/en-us/story/1756215279833769195-toyota-tsusho-azure-professional-services-en-japan)

[什麼是 Azure 虛擬桌面 (AVD)?](https://learn.microsoft.com/zh-tw/azure/virtual-desktop/overview)

### 從 VDI 到 AVD 的轉型

在 2020 年 COVID-19 大流行期間，**豐田通商** 為 3,000 名員工建立了虛擬桌面基礎結構（VDI）。隨著需求增加，本地伺服器無法應付擴展需求，公司於 2021 年開始轉向 **雲端優先策略**，並將 VDI 遷移至 **Azure Virtual Desktop (AVD)**。

---

### 成本效益與靈活性

豐田通商選擇 **AVD** 是基於 Microsoft 的成本效益和靈活服務。他們發現：

- 安全性修補可更穩定地應用，減少硬體故障。
- 目前使用 **Windows 10** 配合 AVD，但也在啟動 **Windows 11 過渡計劃**。

## 筆者觀察：兩種升級策略

以上兩個案例展現了兩間企業採取的不同策略：

1. **白鶴清酒**：全公司部署 Windows 11 Pro。
2. **豐田通商**：透過雲端技術 AVD 過渡到 Windows 11。

這些企業雖然文化背景不同，但在 IT 技術的應用上卻走在前端。筆者非常嚮往 AVD 的工作方式：

> AVD 的便利性
>
> 在筆者過往 onboarding 的經驗中，常需安裝大量工具和軟體。但透過 AVD 的統一管理，軟體與環境版本能更一致，並可方便管理。
>
> **遠端工作** 也變得更輕鬆，筆電僅需作為 client 使用，省電且延長電池壽命。繁重的 Build 任務可留給 AVD 處理。
